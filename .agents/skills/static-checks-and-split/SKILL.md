# The admin UI module graph and its static checks

These traps were learned in this repository and moved here verbatim from `AGENTS.md`;
nothing was paraphrased.

- The admin UI is one ES module graph under `src/admin/static/` that the server serves as the single `/static/app.js` the browser runs; the URL, `index.html` and routes are unchanged, so every probe technique that intercepts `**/static/app.js` still works. `entry.js` calls `startAdminUi()`, `modules/wiring.js` is the composition root, `modules/core.js` owns the one mutable `state` and the language-panel registry, and each feature module imports what it needs from it. `npm run bundle:ui` (`scripts/build_ui_bundle.ts`, esbuild, `format: "iife"`) bundles that graph into `ADMIN_BUNDLE_FILE` at `dist-node/src/admin/static-bundle/admin-app.js`, and the server answers `/static/app.js` with exactly that text. The chunk lives beside the compiled static assets, never inside `src/admin/static`, so `copy_static_assets.ts` and its stale-asset guard stay out of it; `static-assets.ts` finds it by walking up to the directory holding `package.json`, which is the same rule in source, in `dist-node` and inside `app.asar`. A missing bundle is an error at load time, never an empty script - and the read retries `ENOENT` for the same bounded window as a sharing violation, because `[System.IO.File]::Replace` briefly removes the destination (measured: one miss in about ten thousand back-to-back reads, which is what makes `build-ui-bundle.test.ts` flake without the retry), which is why the bundler is wired into `build`, `lint`, `dev` and every test entry point (`test`, `test:coverage`, `test:watch`) and why `startStubAdminServer` in `test-node/ui/admin-ui-server.ts` builds it too; the `pre*` lifecycle hooks stay exactly `npm run rebuild:node` because `test-node/electron/builder-config.test.ts` pins that string so a Node lifecycle can never skip the ABI restore. Proving a packaged build delivered this script means comparing what the packaged server serves at `/static/app.js` with the payload assembled from `app.asar` entries — that one file, read back through `@electron/asar` `extractFile(archive, path)` where the path is backslash-separated and has no leading backslash. The server substitutes the strip-fields placeholder, whose replacement is longer than the placeholder, so raw lengths differ by design: compare after applying that substitution, and show the placeholder present in the packaged payload and absent from the served text, which is what proves the substitution ran. Nothing is published on `globalThis` except the test adapter's frozen `__adminUiTest` object (`modules/test-adapter.js`, installed by the composition root): `applySelectedLogDetail`, `formatCurrencyAmount` and the two config surfaces' `init`/`dispose`/`load`, which the browser suites call instead of the retired `window.proxyConfig`/`setLanguage`/`initializeProxyConfig` globals. A language switch in a test drives the real control (`#languageSelect` plus a dispatched `change`), because `page.selectOption` would steal the focus an assertion may be watching. `npm run lint` runs the bundler and then lints `src/admin/static/entry.js` and `src/admin/static/modules/*.js` directly: these are real modules, so a missing import is `no-undef` and no concatenated `.ui-check/app.js` is needed any more. `npm run typecheck` checks the same files through `tsconfig.ui.json` (`allowJs`+`checkJs`, `strictNullChecks: true`, `exactOptionalPropertyTypes: true`); its `moduleDetection: "legacy"` no longer changes anything now that every file imports a sibling, but leave it alone. Mechanical typing rewrites (`asElement`, `qsOn`, `closestOn`, `String(...)` wrappers) change runtime code, so the UI suite with pixel baselines is the only proof they are behavior-neutral; `test-node/admin/static-source.test.ts` fails if a numbered part reappears in `src/admin/static`.
- The complete UI graph now enables strict null checking in `tsconfig.ui.json`; there is no DOM-only check. `modules/dom.js` returns concrete `HTMLElement` values for general HTML queries and uses constructor-checked `requiredTyped`/`optionalTyped` for controls, with selector-bearing errors for missing required nodes or wrong element classes. `controlsOn` returns an input/select/textarea union, so checked and selection APIs need real class guards. Statistics card filters are created only after a response renders cards; they must remain optional during startup and options loading. `src/admin/ui-contracts.d.ts` owns shared state, async panel and API path/result types; DTO imports need Node type declarations, but the browser code still uses browser APIs at runtime. The API result assertion is the wire boundary; errors are parsed from unknown with field guards. `test-node/admin/ui-types.test.ts` verifies coverage and compiler rejection cases; `test-node/ui/admin-ui-dom-contracts.test.ts` exercises real Chromium lookups and broken initialization. Remaining strict options such as noImplicitAny are separate from the completed null migration.
- `test-node/admin/static-source.test.ts` formats `entry.js` and every module and asserts `src/admin/static` holds only `index.html`/`app.css`/`entry.js`/`modules/` — a numbered part reappearing fails there — while `buildAdminAppJsTemplate()`, the text `loadAdminStaticAssets()` serves, keeps exactly one strip-field placeholder; `test-node/admin/static-bridge.test.ts` (kept under its old name) proves the retired bridge is gone: the only global write is `__adminUiTest`, no production module reads it, every module is reachable from `entry.js` through imports, the display helpers stay DOM-free, and the served `/static/app.js` is byte-identical to `buildAdminAppJsTemplate()` after the substitution. So run `npx prettier --write` on the static files before the full suite - that single guard fails first and is faster than eyeballing formatting. Throwaway browser probes hit the same wall the admin tests already respect: `/api/load-balancer/status` has `additionalProperties: false` with a long `required` list, so a stub fixture missing `canonicalKey`/`failures`/`inRotation` answers 500 and the probe waits for a poll that never fills anything.
