# Windows 自动启动

> 状态：运维手册
> 权威性：Electron 托盘自动启动的当前范围和验证入口。
> 更新条件：登录项实现、托盘生命周期或发布产物变化时更新。

Electron 宿主可以通过 `electron/auto-start.ts` 管理 Windows 登录启动项。自动启动只负责在登录时启动应用，不改变代理 pair 的 `enabled` 配置，也不绕过单实例检查。

验证自动启动时使用隔离用户数据目录和测试开关，不能修改开发机已有的登录项。检查创建、读取、关闭和重复调用都幂等；退出路径必须仍然等待管理端、代理监听器和日志连接关闭。

托盘入口、单实例和退出顺序见 [当前架构](../current/architecture.md)；发布产物验证见 `packaging-smoke` skill。
