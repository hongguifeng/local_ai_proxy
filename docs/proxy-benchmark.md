# HTTP 代理延迟与内存基准

运行：

```bash
npm run benchmark:proxy
```

基准在本机回环地址上启动一个上游和一个 Node 代理，执行：

- 10 次预热请求；
- 100 次直连请求和 100 次代理请求，并发度均为 20；
- 一次 64 MiB 流式二进制响应，响应日志完整正文上限设为 1 MiB。

输出包含直连和代理的 p50、p95、吞吐量、p95 额外开销，以及流式响应期间的 RSS 峰值增量。命令在以下任一条件成立时失败：

- 代理 p95 超过 1000 ms；
- 相对直连的 p95 额外开销超过 500 ms；
- 64 MiB 流式响应期间 RSS 增量超过 192 MiB；
- 客户端未收到完整的 64 MiB 响应。

阈值用于发现数量级回归，不作为跨机器的产品性能承诺。发布前应在目标 Windows 构建机上保存一次输出，作为该版本基线。
